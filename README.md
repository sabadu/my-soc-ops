# 🎉 Soc Ops — Social Bingo

> **Break the ice. Make connections. Have fun.**

Soc Ops is a social bingo game built for in-person mixers, team events, and networking sessions. Players find real people who match each square on their bingo card — the first to get **5 in a row** wins!

---

## 🕹️ How It Works

1. **Get your card** — Each player receives a unique, randomly shuffled 5×5 bingo board.
2. **Mingle!** — Walk around and find people who match the prompts on your squares (e.g. *"has a pet"*, *"speaks more than 2 languages"*).
3. **Mark your matches** — Tap a square once you've found someone who fits.
4. **Shout BINGO!** — First to complete 5 in a row (across, down, or diagonal) wins! 🏆

---

## ✨ Features

- 📱 **Mobile-first** — Designed to be used on your phone during events
- 🔀 **Randomised boards** — Every player gets a unique card each game
- 🆓 **Free space** — Classic centre free square included
- ✅ **Bingo detection** — Automatically detects rows, columns, and diagonals
- 🎊 **Win celebration** — Animated modal when you hit bingo
- 🔁 **Instant reset** — Start a new game with one tap

## 🚀 Getting Started

### Prerequisites

- [Node.js 22](https://nodejs.org/) or higher

### Run locally

```bash
npm install
npm run dev
```

### Build for production

```bash
npm run build
```
